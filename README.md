# Editeur de Markdown → LaTeX

## Présentation

Editeur Markdown → LaTeX est une application web permettant de rédiger un document en Markdown et de le convertir automatiquement en LaTeX.

L'application propose un éditeur Markdown ainsi qu'une zone de prévisualisation permettant de visualiser le résultat de la conversion en latex directement.

Le projet est composé de deux parties :

- un frontend développé avec React ;
- un backend développé avec Python et Flask.

La communication entre le frontend et le backend est réalisée grâce à une API REST.

---

## Fonctionnalités

- Édition de texte en Markdown
- Conversion automatique de Markdown vers LaTeX
- Prévisualisation du résultat
- Communication entre React et Flask
- Conversion automatique après modification du texte
- Mode clair / sombre
- Interface responsive
- Gestion des erreurs de communication avec le backend

---

## Syntaxe Markdown prise en charge

L'éditeur de Markdown → LaTeX prend en charge plusieurs éléments de la syntaxe Markdown et les convertit en LaTeX :

- Titres
- Paragraphes
- Listes à puces
- Listes numérotées
- Listes imbriquées
- Lignes horizontales
- Liens
- Images
- Citations
- Code en ligne
- Blocs de code
- Tableaux
- Retours à la ligne
